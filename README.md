# CodeAlpha Cybersecurity Internship Tasks

This repository contains the completed task submissions for the CodeAlpha Cybersecurity Internship program.

## Repository Contents

* **`Task-1-Network-Sniffer/`**
  * `sniffer.py`: Python network packet capture tool using Scapy to analyze traffic protocols and IP headers.
* **`Task-2-Phishing-Awareness/`**
  * `Phishing_Awareness_Training.md`: Comprehensive educational training module on phishing vectors, red flags, and mitigation.
* **`Task-3-Secure-Code-Review/`**
  * `secure_code_review.py`: Code review demonstrating vulnerable vs. remediated Python authentication scripts.
  * `Code_Review_Report.md`: Full audit report detailing OWASP/CWE findings and security best practices.
