# CodeAlpha Cybersecurity Internship Tasks

This repository contains the completed tasks for the CodeAlpha Cybersecurity Internship program.

## Repository Structure

* **`Task-1-Network-Sniffer/`**
  * `sniffer.py`: A Python script built with `scapy` to capture and log network packets, displaying source/destination IPs and protocols (TCP/UDP/ICMP).
* **`Task-2-Phishing-Awareness/`**
  * `Phishing_Awareness_Training.md`: A comprehensive educational module covering phishing attack vectors, red flags, social engineering tactics, and an interactive quiz.
